## Today's original post — DRAFT, NOT PUBLISHED

> A supplier sends you an FCC ID for a Bluetooth accessory. What should you verify before relying on it?
>
> Start with a simple match:
> 1. Search the ID in the FCC Equipment Authorization System.
> 2. Compare the grantee and device/model details with the product you will actually sell.
> 3. Check that the listed radio functions and configuration match the finished product—not just a similar model or an included component.
> 4. If the product has changed or the records don't line up, ask the responsible compliance professional or TCB whether the authorization covers that configuration.
>
> An FCC ID is not a blanket approval for every product requirement, every sales market, or every platform document request. Also, FCC pathways vary by device; a seller should not infer that every electronic product must carry an FCC ID.
>
> The FCC's enforcement order includes case-specific examples where an ID provided for a device did not apply or did not cover the device's full capabilities. Start with the FCC's own equipment-authorization search: https://www.fcc.gov/oet/ea/fccid
