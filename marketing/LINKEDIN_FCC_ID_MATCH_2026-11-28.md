## Copy

If a marketplace asks for an FCC ID, don't substitute a model number—or an FCC ID from a similar product.

For a Bluetooth or Wi-Fi product, the useful check is not just “does this ID exist?” It's “does this FCC ID apply to the exact device and version I'm listing?”

Before replying to a marketplace request:

• Ask the supplier which FCC ID applies to the exact product/model and whether the authorization is for the device itself or a separately certified module.
• Search the ID in the FCC Equipment Authorization System. A database match shows the ID record exists; it does not, by itself, prove that a module's approval applies to every host product or integration.
• For a “Contains FCC ID” module, ask for the grant conditions and confirmation that the host device's antenna, RF exposure, labeling, and integration meet them.
• Keep FCC ID separate from model, serial, UPC, IMEI, CE mark, or a generic “FCC certificate.” These identifiers and documents are not interchangeable.

eBay says similar-looking products can have different transmitters, antennas, wireless modules, or regional configurations, and an FCC ID in the database is not by itself proof that it covers your listing. It may request the ID for selected listings; that is distinct from the product's underlying legal requirements.

## Accuracy notes

- eBay's page is first-party guidance for eBay listings, not every marketplace. The post says “a marketplace” and attributes platform-specific claims to eBay.
- The Federal Register rule set effective Oct. 13, 2026 for its general effect; marketplace FCC-ID display dates are Mar. 1 and Jun. 1, 2027, with exclusions and different treatment based on marketplace role. Do not imply every small seller must update every listing on those dates.
- An FCC ID found in the database establishes the ID record exists, not that it matches the specific product; the seller must verify the match.
- A modular transmitter grant may be usable in a host device subject to its conditions; don't claim a module ID is automatically insufficient or automatically sufficient for the finished product. Verify the specific grant and the marketplace's listing instruction.
