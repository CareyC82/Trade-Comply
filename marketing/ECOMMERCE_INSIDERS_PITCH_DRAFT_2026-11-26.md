# Before ordering another product test, match the report to the exact item

When an online marketplace asks for product-safety documents, a seller may face a costly question: can an existing supplier report be used, or is new testing needed? Before commissioning work, first check whether the report actually covers the item in the listing and what the reviewer is asking for.

This is an evidence-organization step, not a way to bypass required testing. A marketplace or qualified testing, inspection and certification (TIC) provider makes its own decision under the applicable policy.

## 1. Anchor the check to the request

Record the marketplace, affected listing or ASIN, the exact request text, the date received and the stated deadline. “Battery documents” or “safety certificate” may be too broad to identify the requested evidence. Use the platform’s current notice and submission path rather than relying on an old email or a forum answer for a different item.

## 2. Match the report to the product that will be sold

Compare the model, part or item number and manufacturer shown on the listing with the report and product label. For battery-powered goods, also note the battery model and configuration where the documents identify them. Check whether the report refers to a single item, a bundle, a different battery pack or a model variant. A similar product name is not enough to establish that the report covers the same product.

If a detail is missing or inconsistent, ask the supplier to clarify it in writing. Do not edit a test report or change identifiers to make it appear to match.

## 3. Index the evidence without changing it

Create a simple table with one row per document: file name, report or certificate number, exact model listed, issuing lab, issue date/version and the question it might answer. Keep the original files intact. This makes it easier for a reviewer to identify what is present and what still needs clarification.

## 4. Separate the decision-makers

The supplier can confirm what was manufactured and which components were used. The seller can map those facts to the listing and respond to the account notice. A lab or authorized TIC provider evaluates the testing evidence it receives. The marketplace decides whether its own listing requirements are met. One party’s document is not automatically a decision by another.

For example, Amazon’s U.S. direct-product-validation guidance allows existing documents to be submitted to an Amazon-authorized TIC provider for review. The provider determines whether they meet the applicable policy; the guidance does not promise acceptance or rule out additional testing.

## 5. Ask what a new test would resolve

Before paying for repeat testing, ask the reviewer to identify the specific gap: wrong or unclear model coverage, missing report pages, an outdated test, a different product configuration, or a requirement for new testing. Then compare that answer with the platform notice and deadline. If new testing is necessary, the seller can proceed with a clearer scope.

The goal is not to avoid tests. It is to make the next step traceable: which exact item is being reviewed, which evidence supports it, and who decides whether that evidence is sufficient.

**Source:** Amazon, [Direct product validation: Third-party testing, inspection, and certification services](https://sellercentral.amazon.com/help/hub/reference/external/GUTZ2R2DD6P2UMVB).
